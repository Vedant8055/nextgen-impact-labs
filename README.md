# NEXTGEN IMPACT LABS — Website Prototype

A responsive single-page website prototype for NEXTGEN IMPACT LABS, a youth-led social innovation forum focused on Nashik and North Maharashtra.

## Run locally

No build tools or package installation are required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local web server, run one of the following from this folder:

   **Python**
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

   **Node (if installed)**
   ```bash
   npx serve .
   ```

## Included

- Responsive desktop, tablet and mobile layouts
- Custom visual identity and logo treatment
- Hero, story, four impact pillars, approach timeline and founders
- Regional focus visual, initiative/theme gallery and filters
- Transparency hub and SDG alignment
- Collaboration cards and contact form prototype
- Interactive modals, mobile menu, scroll reveals and progress bar

## Important before publication

This is a design and interaction prototype, not a live NGO platform. Please confirm Yuvaan's surname and review all founder details before publishing. Founder profile visuals are intentionally typographic placeholders rather than generated portraits. Impact statistics, project history, partner names, registration details, policies, reports and contact information have not been invented and must be added only after verification.

The enquiry form currently demonstrates front-end validation and a local success state only. It does not send email or store submissions. Connect a secure backend or approved form provider before launch. No payment or donation processing is configured.

The photographs are illustrative editorial references loaded from remote third-party image URLs. They are not documentation of NEXTGEN IMPACT LABS activities. Confirm rights, attribution and suitability before production use; replace them with properly licensed or organisation-owned photography where appropriate. An internet connection is needed to load remote images and Google Fonts; CSS treatments provide fallback styling if remote imagery is unavailable.
